# ibScale MP Feeder - Hardware R2 Migration Guide

The R2 revision of the **ibScale MP Feeder** board introduces a major overhaul of the STM32F411CEU6 pinout and peripheral layout. The primary goal of this revision is to route the quadrature encoder inputs onto a 32-bit hardware timer (`TIM2`) while optimizing signal routing and improving power/thermal rail diagnostics.

This document outlines the physical pin and peripheral changes between R1 and R2, and details the accompanying firmware/software configuration updates.

---

## 2. Key Architectural Upgrades in R2 Layout

* **32-Bit Hardware Encoder**:
  R1 used a 16-bit timer (`TIM3`) for the encoder, which had a wrap-around limit of `65,535` ticks. R2 routes the encoder onto the 32-bit **`TIM2`** peripheral (`PA0`/`PA1`), allowing a maximum hardware count of up to `4,294,967,295`. This virtually eliminates high-speed wrap-around errors and drastically simplifies tracking logic.

* **Reallocated H-Bridge Motor Control**:
  By moving the encoder off `TIM3`, the motor drive and peel H-bridges have been consolidated onto **`TIM3`** (Channels 1–4) instead of `TIM4`. This keeps all high-current inductive drivers grouped onto a single timer interface.

* **USART1 for RS485**:
  The RS485 transceiver now uses **`USART1`** (`PB6`/`PB7`) instead of `USART2`. `USART1` is a higher-speed peripheral capably clocked on the high-speed APB2 bus, ensuring lower latency communication.

* **Better ADC Noise Immunity**:
  The dual analog rail monitors (24V VDC and 10V Buck rail) have been reassigned to `PA3` and `PA4` (`ADC1_IN3` and `ADC1_IN4`). Placing these analog lines near the MCU's analog reference core (`VDDA`) improves reading precision and shields them from motor switching noise on the `PB0`/`PB1` lines.

## 3. Firmware Configuration Changes (Completed)

To support these hardware updates, the following software configurations have been fully applied in the `mpy/` codebase:

### 1. Board Pin Mapping (`mpy/pins.csv`)
All functional pin aliases are redirected to their R2 GPIO locations. The authoritative design mapping has been updated to refer to `pcb/ibScaleMPFeeder.ioc` (STM32CubeMX project file).

### 2. MicroPython Board Header (`mpy/mpconfigboard.h`)
The C-level UART registry configuration has been updated to route the `"RS485"` bus to **`UART1`** (mapped to the updated RTS pin `pyb_pin_RS485DE` on `PB8`).

### 3. Software System Defaults (`mpy/lib/defaults.py`)
* **`DRIVES`**: Updated `TIMER_ID` to `3`. Re-mapped channels: 
  - `PEEL1_CH` -> `3` (PB0)
  - `PEEL2_CH` -> `4` (PB1)
  - `DRIVE1_CH` -> `1` (PA6)
  - `DRIVE2_CH` -> `2` (PA7)
* **`ENCODER`**: Updated `TIMER` to `2`, `TIMER_AF` to `1` (`TIM2` uses AF1 on `PA0`/`PA1`), and `MAX` count limit to `4294967295`.
* **`RS485`**: Updated `UART_ID` to `1`.

### 4. Hardware Drivers (`drives.py` & `rs485.py`)
Class constructor fallback default signatures have been updated to target the new R2 peripheral IDs (`timer_id=3` for H-bridge and `uart_id=1` for RS485) ensuring standalone manual testing matches actual hardware.

## 4. Switching Hardware Profiles via REPL

If you are running a single unified firmware image and need to toggle the runtime configuration between R1 and R2 profiles, drop to the MicroPython REPL and execute the following commands:

### Switch to R1 Configuration
```python
# The global 'SYSCONFIG' instance is automatically initialized at boot in main.py
# If doing manual setup or from an external script:
# from system.sysconfig import SysConfig
# SYSCONFIG = SysConfig()

# 1. Set Drive Motor Timers and Channels
SYSCONFIG.set('DRIVES.TIMER_ID', 4)
SYSCONFIG.set('DRIVES.PEEL1_CH', 1)
SYSCONFIG.set('DRIVES.PEEL2_CH', 2)
SYSCONFIG.set('DRIVES.DRIVE1_CH', 3)
SYSCONFIG.set('DRIVES.DRIVE2_CH', 4)

# 2. Set Encoder Timer (16-bit TIM3, AF2)
SYSCONFIG.set('ENCODER.TIMER', 3)
SYSCONFIG.set('ENCODER.TIMER_AF', 2)
SYSCONFIG.set('ENCODER.MAX', 65535)

# 3. Set RS485 (UART2)
SYSCONFIG.set('RS485.UART_ID', 2)

# Save changes to sysconfig.json and soft reboot
SYSCONFIG.save()
reboot()
```

### Switch to R2 Configuration
```python
# The global 'SYSCONFIG' instance is automatically initialized at boot in main.py
# If doing manual setup or from an external script:
# from system.sysconfig import SysConfig
# SYSCONFIG = SysConfig()

# 1. Set Drive Motor Timers and Channels
SYSCONFIG.set('DRIVES.TIMER_ID', 3)
SYSCONFIG.set('DRIVES.PEEL1_CH', 3)
SYSCONFIG.set('DRIVES.PEEL2_CH', 4)
SYSCONFIG.set('DRIVES.DRIVE1_CH', 1)
SYSCONFIG.set('DRIVES.DRIVE2_CH', 2)

# 2. Set Encoder Timer (32-bit TIM2, AF1)
SYSCONFIG.set('ENCODER.TIMER', 2)
SYSCONFIG.set('ENCODER.TIMER_AF', 1)
SYSCONFIG.set('ENCODER.MAX', 4294967295)

# 3. Set RS485 (UART1)
SYSCONFIG.set('RS485.UART_ID', 1)

# Save changes to sysconfig.json and soft reboot
SYSCONFIG.save()
reboot()
```
